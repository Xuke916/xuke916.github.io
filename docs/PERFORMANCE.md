# 2026-11-25 性能复核

本次保留现有布局、内容与动画节奏，减少滚动过程中不必要的主线程工作。

- 首页双栏入口静止后不再重复写入人物、文字遮罩和背景位置；视口变化仍重新计算。
- 页眉配色、照片扇形上浮进度与分类导航只在状态变化时更新。
- 生活页照片序列的计数位置改用 `transform`，避免逐帧修改 `top` 触发布局。
- 专业作品页文字逐行擦开先统一测量、再统一更新 DOM，避免逐段读写交错；动画完成后释放遮罩节点。静止的简历不再响应无关的鼠标移动刷新。
- 首页人物、头盔和 Rewinder 封面改用保留原尺寸与透明背景的 WebP；原有手机尺寸资源继续按视口选用。三张资源合计由 3,392,765 字节降至 738,950 字节，约减少 78%。

## 对比方法与结果

在同一台电脑上，用本地 Edge、390×844 视口、4 倍 CPU 降速，分别对修改前后执行相同的 90 帧滚动采样，启动阶段不计入滚动指标：

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 生活页布局计算次数 | 89 | 19 |
| 专业作品页 DOM 变更记录 | 202 | 111 |

这些指标反映该采样中的布局与 DOM 工作量，不代表所有手机的实际帧率，也不承诺任意硬件固定满帧。原始测试日志、浏览器配置和工具留在本地，不随网站发布。

## 验证范围

`pnpm check` 覆盖 15 种视口、路由与返回、菜单、触控和键盘、响应式资源、流体与媒体暂停、图片放大、语言切换、文字逐行揭示及清理。另以本地浏览器检查桌面 1440×900 和手机尺寸 390×844 的首页、双栏入口、专业作品、生活页与四个独立案例，复核脚本错误、图片加载和横向溢出。尺寸模拟不替代手机硬件实测。
